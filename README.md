# Urmi Barman --- Personal Portfolio

A personal portfolio website showcasing my background as a Computer
Science and AI student, the skills I am learning, projects I have worked
on, education, and interests.

## Features

-   Home section with an introduction and links to projects and contact.
-   About section covering my background and current focus.
-   Skills section for web development, computer science, data science
    and AI, and areas I am exploring.
-   Projects section featuring Spotly and this portfolio website.
-   Education timeline and personal learning journey.
-   Open To section for collaborations, internships, hackathons, and
    learning opportunities.
-   Contact section with a message form.
-   LinkedIn and GitHub profile links.
-   Responsive layout for desktop, tablet, and mobile screens.
-   Accessibility considerations, including semantic HTML, form labels,
    navigation labels, and reduced-motion styling.

## Built With

-   HTML5
-   CSS3
-   Google Fonts: Inter and PT Serif
-   JavaScript file reference for social-link behavior (`script.js`)

## Project Structure

``` text
MyPortfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

Keep these files in the same project folder unless you update the file
paths in the HTML.

## Run Locally

1.  Open the `MyPortfolio` folder in Visual Studio Code.
2.  Open `index.html` in a browser, or use the Live Server extension in
    VS Code.
3.  Edit `index.html` to update text and sections.
4.  Edit `style.css` to change colours, spacing, typography, and
    responsive layouts.

## Before Publishing

-   Check that the LinkedIn and GitHub URLs point to the correct
    profiles.
-   Add repository or live-demo links for projects when available.
-   Make sure education details and dates are up to date.
-   The contact form is currently only a front-end layout. It will not
    send messages until it is connected to a backend or form-handling
    service.
